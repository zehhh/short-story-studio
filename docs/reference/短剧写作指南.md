## 一、核心基础认知

### 1. 什么是短剧？
- 在抖音、快手等短视频平台发布的**短视频连续剧**
- 每集1-1.5分钟，整本80-100集，总时长约100分钟（也有60、80分钟版本）
- 剧本约4-5万字，每集剧本500-700字

### 2. 目标受众
- 以**35-60岁**的下沉市场群体为主
- 文化程度不高，需要用强冲突、直白情绪吸引眼球

### 3. 核心原则
- **情绪大于情节**：用夸张、极端的剧情和强烈的冲突，在极短时间内调动观众情绪
- 人物动作、台词和剧情都为情绪服务
- 够夸张、极端才能拉扯出更强烈的情绪

### 4. 热门题材
| 频道 | 题材 |
|------|------|
| 男频 | 战神、神豪、小人物逆袭 |
| 女频 | 甜宠、闪婚、萌宝、复仇、社会热点、信息差 |

### 5. 审核流程与稿费（参考）
- 稿费范围：**7000-15000元/本**（根据质量浮动）
- **初审**：投稿前5集+大纲，通过后写前十集
- **终审**：投稿前十集+大纲+人物小传，通过后签约
- **签约**：支付定金（稿费10%-30%），25天内完成整本

## 二、剧本创作核心技巧

### 1. 节奏与结构

#### 拉快节奏的方法
- **开篇**：第一集就要呈现主题，调动情绪，爽点足，钩子吸引人
- **台词**：要短、有爆发力，不能大段堆砌
- **矛盾前置**：不需要太多铺垫，开篇即矛盾
- 每集都需要矛盾点、爆发点、爽点，结尾需要钩子

#### 前十集公式
| 集数 | 任务 |
|------|------|
| 1-2集 | 强冲突开场（扇耳光、车祸、羞辱、大哭、大怒、尖叫），拉满情绪，吸引眼球 |
| 3-4集 | 剧情过渡，拉出主线，交代主角目标，让剧情更自然 |
| 5-8集 | 多方配角持续施压，压抑情绪递进（如想离婚却怀孕、被领导骚扰、被亲人误解） |
| 9-10集 | **付费卡点**。危机即将到来、秘密将揭露、爽点将爆发，悬念拉到最高 |

#### 100集体量节奏
- 前30集每集都要有冲突打脸和钩子
- 可按“起承转合”分阶段写大纲（如1-20集为一个阶段，20-40集为下一阶段）
- 先定大纲的首尾，再填充中间
- 剧情递进增加情绪拉扯程度

### 2. 冲突与爽点

#### 冲突设计要求
- **冲突必须新颖、有创新**，尖锐、震撼
- **先想爽点，再设计冲突**：冲突的核心内容根据爽点来构造
  - 例：金手指是获得亿万家产 → 前期冲突就是因为穷被欺压
  - 女频爽点围绕感情：男主误会虐女主，却发现女主得绝症/是豪门千金/孩子是男主的
- **冲突尽量发生在主角身上**（发生在别人身上的危机无法带来紧张感）
- 开头部分冲突尽量发生在主角身上，其次是与主角高度相关的人物

#### 强化冲突的方法
- 施力点要狠，受力点伤害要大，反馈越强冲突越强
- 剧情平淡时，尝试构造更强的冲突事件（如把“出轨”升级为“杀父仇人”）
- 每集设置核心事件，台词围绕事件展开

#### 爽点来源（30个典型）
1. 主角是一方霸主，周围人都把他当菜鸟欺辱

3. 普通物品在主角手里就是神器

5. 被原团队抛弃，自己创立更强团队，原团队求回归被拒
6. 反派以为主角放大招后重伤，谁知还有更大招
7. 反派可望不可即的物品是主角发明的
8. 幸运体质，逢凶化吉
9. 扮猪吃老虎，借别人之手打脸反派
10. 被诬陷陷入绝境，反转反杀
11. 重生改变命运，弥补遗憾

13. 所有人都以为主角必死，主角却披着更厉害的马甲出现
14. 主角每次都表现得比配角好一点，玩弄配角于股掌

### 3. 台词与人设

#### 台词要求
- **口语化、简短有力、言简意赅**
- 体现个人特色：霸总能命令时不请求
- 在戏剧情景里配合人物动作产生，推动剧情
- 每句台词都要经过提炼，不要废话
- 多用命令语句（给我滚、闭嘴、放手）——自带强情绪
- 用“立刻、马上”等时间限制词促进压迫感

#### 人设要点
- 人物**单一扁平化**，情绪极端（少见多怪、大喊大叫、不通情理）
- 前期体现虐、恶心等情绪，后期可洗白或设计自杀/不原谅
- 反派的话越粗俗难听越好
- 善用“**反差人设**”增加看点

### 4. 钩子与悬念

#### 钩子的定义
- 每集结尾设置的悬念，让观众想看下一集
- 在冲突高潮时卡点结束
- 好的钩子能吸引观众付费

#### 钩子设置方法
| 方法 | 说明 |
|------|------|
| 留悬念 | 抓到反派时突然卡点，或发现蛛丝马迹时卡点 |
| 人物表情 | 人物露出不可思议、害怕、疑惑的表情后卡点 |
| 谈话中断 | 聊到关键部分突然停止 |
| 突然喊话 | 住手、停手、松手，然后卡点 |
| 新人物出场 | 被主角打脸的反派找来老大欺压主角 |
| 新事件发生 | 解决一个障碍后，引起另一个阻碍 |
| 情绪起伏 | 主角的喜怒哀乐、震惊、不可思议作为卡点 |

#### 常用悬念位置
- 打斗场面、暧昧场面
- 主角关键时刻出场解围
- 电话打来，表情凝重
- 神秘人出现
- 台词“不好了”、“坏了”

## 三、剧本格式与规范

### 1. 标准格式

#### 场次标题格式
```

1-1 日 内 穆府大厅

```
- `1-1`：第一集第一个场景
- `日/夜`：白天/晚上
- `内/外`：室内/室外
- `地点`：别墅/酒店/广场等

#### 完整示例
```

第一集

1-1 日 内 穆府大厅
出场人物：陈诺、温言、穆庭琛、刘妈

△老管家陈诺牵着八岁的温言来到客厅，站在穆霆琛面前。

老管家：少爷，这就是温志远的女儿温言，我给您带过来了。

△穆霆琛居高临下看着小女孩，眼中是极寒。

穆霆琛（冷声）：你父亲死了，从现在起，他的罪，你来赎！还有，不许叫我哥哥，只能叫我的名字，穆-霆-琛！

字幕：十年后

1-2 日 内 穆府杂物间
出场人物：温言、刘妈

△温言小心翼翼地回到狭窄潮湿的杂物间，动作麻溜地放下背包。

保姆刘妈：言言，今天别帮我忙活了，少爷今天回来了！

温言（一惊）：穆霆琛回国了？

刘妈：对啊，少爷出国三年了，好不容易回一趟家，说是想找你，哎……你当心点，能不说话就不说话，省得又让他不高兴，讨苦吃。

```

#### 符号说明
| 符号 | 含义 |
|------|------|
| `△` | 除对话外的内容（叙述、动作） |
| `os` | 内心独白 |
| `Vo` | 画外音（人未到声先到，或电话中只闻其声） |
| `【闪回】` | 回忆开始 |
| `【闪出】` | 回忆结束 |
| `/` | 多场景连续闪回或互切时分隔 |

#### 台词情绪标注
```

沈初晴（浅笑）：你终于来了。
穆霆琛（冷声，眼神如刀）：滚出去。

```

### 2. 写作禁忌

| ❌ 不要做 | ✅ 要做 |
|-----------|---------|
| 大量环境/心理描写 | 将心理活动转化为台词、动作、表情 |
| 铺垫过多、切入太慢 | 矛盾前置，开篇即冲突 |
| 逻辑不通，事件割裂 | 琢磨人物动机，理顺逻辑 |
| 配角太多，人物混乱 | 控制出场人物数量 |
| 使用生僻字 | 用常见字 |
| 秀文笔、用成语文言文 | 台词接地气 |
| 写“一夜旖旎”“她将反派赶走”等抽象描述 | 具体写出动作和台词 |
| 大段独白 | 台词简短，每句都有信息点 |

### 3. 特殊场景处理

#### 场景互切（如打电话）
```

△跟班摁着沈初晴，李雪撸起袖子准备扇向沈初晴

萧南Vo：谁敢动沈氏集团的大小姐！

△萧南走进来

```

#### 内心独白与实际台词并存
```

温言os：他居然回来了……
温言（低头）：穆少爷好。

```

## 四、创作流程与大纲

### 1. 创作步骤

1. **先定首尾**：确定故事的开端和结局
2. **写人物小传**：年龄、性格、背景、与主角关系、命运结局
3. **写大纲**：事件的罗列，非描述
4. **写分集梗概**：一句话说清楚每一集的核心事件
5. **写正文**：围绕本集中心事件展开

### 2. 人物小传要素
- 性别、年龄、形象气质
- 主角/反派/配角？与主要角色的人际关系
- 有情感线的要说明情感线关键节点
- 性格有变化的要标注变化事件和变化后状态
- 存在意义：给制作组选演员参考，给演员快速了解角色

### 3. 大纲写作规范

#### 大纲内容要求
- **简洁明了**：一句话说清楚一件事
- **剧情连贯**：逻辑通顺，每个剧情之间的联系要想好
- **事件罗列**：避免描述性写法，直接说明事件
- **可分阶段写**：1-20集一个阶段梗概，20-40集下一个，以此类推

#### 大纲模板
| 项目 | 字数 |
|------|------|
| 故事梗概 | 100-150字 |
| 主线 | 200字 |
| 支线 | 200字 |
| 故事发展 | 100字 |
| 故事高潮 | 100字 |
| 故事转折 | 100字 |
| 彩蛋（可选） | 50-100字 |
| 集纲 | 一句话概括 |

#### 集纲写作法
- 列一句话冲突事件
- 拆分成起因、经过、结果
- **起因**（10%）：以强烈冲突动作开头（擦边、抽耳光、扔出去）
- **经过**（80%）：羞辱主角为主，增强观众对反击的期待
- **结果**（10%）：留钩子（陷害、质疑等）

### 4. 背景信息穿插
- 尽量用人物对话展现
- 少用闪回
- 大背景在正文中不需要特意解释，但在对话中时不时带出来

## 五、进阶技巧与市场

### 1. 创新方法
- **多看同类小说和短剧**，积累“梗”
- 将已有梗进行**重新组合**，形成新的梗
- **微创新**：人设创新、反套路创新
- 选择经过市场筛选的题材（爆款小说改编成功率更高）
- 可看点众、番茄、七猫等小说平台寻找合适的梗

### 2. 危机感塑造

| 方法 | 说明 |
|------|------|
| 信息差 | 主角身边的人不知道主角已帮其解决麻烦，自己找反派陷入危机 |
| 时间锁 | 给任务设时间限制，做不到就有无法承受的结局；最后一秒营救 |
| 生死局 | 主角陷入危机，一旦无法解决就会死（常与时间锁同用） |

### 3. 情绪拉扯
- 情绪的本质是矛盾，矛盾是角色之间的对抗
- 角色之间不断博弈较量，就有了拉扯感
- 矛盾来源：男主vs女主、男主vs女配、女主vs女配、女主vs男配、男主vs男配

### 4. 如何拉片（分析爆款）

编剧拉片不是分析镜头，而是：
- 了解每集发生的剧情，分析**剧情节奏**
- 分析如何**起承转合**，高潮点、打压点在哪里
- 代入观众角度，标注情绪起伏点
- 分析每个剧情点对全剧的推动作用
- 观察如何设计剧情控制时长
- 记录**灵感、写作方法、可套用的强情绪台词**
- 拉的是故事节奏：虐点、冲突、情绪递进、冲突放大与升级、打脸情节

### 5. 常用计谋（27种）
反间计、美人计、借尸还魂、胜追穷寇、大器免成、计中有计、得道多助、关门捉贼、偷梁换柱、狐假虎威、苦肉计、指桑骂槐、瞒天过海、添油加醋、反客为主、招摇撞骗、黄袍加身、落井下石、借题发挥、趁火打劫、兔死狗烹、步步为营、以毒攻毒、调虎离山、礼尚往来、顺水推舟、以暴制暴、连环计、屈打成招

### 6. 投稿建议
- 正文写到**付费卡点处（6-10集）**，每集550字左右
- 附上人设、大纲、剧本介绍（约1500字）
- 稿件需包含：故事梗概、亮点、人物小传、分集梗概、正文

### 7. 爆款剧情元素

#### 相爱相杀
复仇、报恩、偿债、婚约（相亲/契约/退婚/替嫁）、拜师、结交、结仇

#### 寻宝奇迹
奇遇、寻宝、找人、探索未知（查案/洗冤）、发现创造、撞破秘密、误会、伤病

#### 英雄救美
拯救、保护、威胁、背叛欺骗、竞争、入侵、征服、出逃、求生

#### 爱恨情仇
恋爱（暗恋/单恋/暧昧）、追击、成长升级、掉马（暴露身份）、转换、角色扮演、复活、陷入麻烦、养成、改命、错位、旅行

#### 暗黑病娇
交流、自我批判、预知、诅咒、一个救一个送、拍卖、变废为宝、打劫、人前显圣、骨肉相残

## 六、新人常见问题与建议

### 常见问题及解决方法

| 问题 | 解决方法 |
|------|----------|
| 台词力度不够、无用台词过多 | 每集设核心事件，台词围绕事件，动作语言再激烈一点 |
| 动作描写不够精简 | 去掉所有形容词和细节动作，剧本是教演员怎么演的 |
| 剧情冲突性不够强 | 构造更强冲突事件（如出轨→杀父仇人） |
| 剧情不符合短剧定位 | 多看短剧，找定位，不建议继续修改 |
| 剧情突兀 | 琢磨主角和配角动机，合理化行为 |
| 大纲主线不明确、情节松散 | 先定首尾，围绕主线展开 |
| 节奏慢、缺乏吸睛点 | 矛盾前置，每集都要有冲突打脸 |
| 同质化严重 | 做微创新（人设创新、反套路） |
| 配角太多、人物混乱 | 控制出场人物 |
| 大纲体量太少撑不起100集 | 分阶段写大纲，每阶段有起承转合 |
| 逻辑不通、割裂感 | 理顺事件因果关系 |
| 铺垫太多、切入太慢 | 开篇即冲突 |
| 忽略人物小传 | 先写小传再写大纲正文 |
| 背景冗长 | 用对话穿插，少用闪回 |
| 忽略拍摄成本 | 考虑场景、人物数量 |

### 三条核心建议

1. **写剧本用不到天赋**：只要肯花时间拆解爆款短剧、分析框架、努力写，就可以成功。

2. **不要想当然**：不要沉浸在自己的世界里，要去分析市场，写符合市场风向的剧本，而不是自己想当然的剧本。

3. **不要铺垫**：剧本要的是画面感、强冲突、强烈矛盾。一件事直接矛盾前置，不要铺垫事件背景和起因。
