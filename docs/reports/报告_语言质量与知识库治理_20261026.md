## 二、用户四项诉求，逐项落在哪

### 1. 「句子不符合中文语序」
- 判据：`language._local_order()`（数量词后置倒装 + AA 叠词连用）
- 修复：`rewrite_order()`（倒装前置、叠词去重）
- 预防：`prompts/draft.md` 加硬判据，`data/craft.json` 加 `order` 类范例 4 组
- 结果：8 篇实测 0.0–0.23/千字，均在 0.3 线内

### 2. 「细节描写详略不当」
- 判据：`_local_detail()`（超长无对话段）+ `audit.sections()`（节长极差）
- 修复：`balance()`（按均值补短节/压长节，**交付前再校一次**）+ `split_paras()`
- 结果：节长极差 1.23–1.93（限 2.0）；详略密度 ≤0.34（限 0.6）

### 3. 「重复描写、细节表述冗余」
- 判据：段落级重复（`dup`）+ 同一信息换词重述（`redundancy`）+ 对白贴标签
- 修复：`dedupe_paras()`（零 token 机械去重）、`defect_brief` 定点返修清单
- 结果：冗余 0.0、重复 0.0（8 篇全部）

### 4. 「一句话拆成好几个短句」
- 判据：`_local_chain()`（**同主语连排 ≥3 句且每句 ≤22 字**），与修复端 `merge_chain_sentences()` **共用同一个 `_chain_member()` 判据**
- 关键修正：对话按**引号深度**判定（`sents_with_dialog()`）——此前「我有凭证！你卷走我买房钱！」被当成 5 个碎句
- 长句与碎句**分开计量**：`longsen` 单列（此前 22 个长句被算成 22 个碎句）
- 结果：碎句 0.0/千字、碎句链 0.0（限额 0.6）

## 三、本轮修掉的真实缺陷（按严重度）

| # | 缺陷 | 后果 | 修法 |
|---|---|---|---|
| 1 | 检测判据 ≠ 修复判据 | 返修五轮分数不动（改不掉的残余） | 抽 `_chain_member()` 单一判据，检测/合并共用 |
| 2 | 重写坍缩不设防 | 1100 字章节被 583 字片段替换（历史 9.9 万字事故同源） | `_guard_rewrite()`：0.75–1.6 倍硬守卫，全 7 处重写入口统一 |
| 3 | 章级门阈值低于最小可测量子 | 一条 3 句链 = 4.0/千字 > 3.0 → 短章永远过不了门，白烧写手 | `CHAPTER_TARGET_SCALE = 15.0`（9.0/千字，5 句起回修） |
| 4 | 对话句被句号截断 | 整段台词算碎句，e2e7 唯一失败项是假阳性 | `sents_with_dialog()`，按引号深度标对话 |
| 5 | 终稿复查空转 | 三轮只收到 556/495/462 字"片段"，2700 token 白烧 | 检测 `text == body` 即 `no_progress` 止损 |
| 6 | 体检 / 投稿 / 看板三套判据 | 同篇稿子"体检 B / 投稿 A / langqa false" | 判据上收 `studio/audit.py`，三处消费同一函数 |
| 7 | 交付前节长被全稿重写拉歪 | balance 报 1.79，成稿实测 2.08 → 判 C | 装配前复校极差，留痕 `lang_balance_final` |
| 8 | 评分卡脏键 | 模型输出 `"，id"` 带中文逗号 → 覆盖率 6%，主编分常年 None | `util.clean_json_keys()` 在 `extract_json` 三个出口统一清洗 |
| 9 | 主编手填分与评分卡矛盾 | 手填 4.5 vs 评分卡折算 7.0，门禁全 `maxed_review` | `review.score_from_criteria()` 优先，手填只留痕 |
| 10 | 终审分久居 58–66 | 无 high 硬伤也被扣到不可发 | `prompts/polish_fix.md` 判分纪律 + 72–82 区间锚点 |
| 11 | 语言打磨静默失效 | `len(int)` TypeError 被 `except` 吞掉，上线以来从未真正运行 | 兜底必须留痕（决策 4）+ 异常写 `report` |
| 12 | 用户选题被自己的禁用表否决 | 选题含「存折」→ 整篇重做主冲突，连挂两轮 | `banned_exempt`：只放行选题里出现的词 |
| 13 | 字数口径打架 | 正文 7997 达标但投稿全文含导语 8430，平台按正文拒稿 | `submit_words` 单列 + `word_gate` 预留清理损耗 |
| 14 | 欧化误报 | 正常词「日子有着落」判翻译腔 | `有着(?!落|数|了)` |
