`[旧版] :1408-1417` 只在 `_english_think_leak` 为真时剥离/重试。思维链里大量引用中文 beat（"岑小满一身剑冢泥出现在登记台队伍末尾…"），首 400 字中文字符 **远大于 10**，于是 `cn < 10` 不成立 → 判为非泄漏 → **整份思维链直接 `write_text` 落盘**（`:1420`），并以 `history` 继续喂给下一章（`:1424`），导致后续章节继续"续写思维链"。

#### 缺陷 C（放大器）：`word_gate` 压缩分支目标与守卫自相矛盾 —— 数学死锁

代入本案：`now=18992, total=193851, ceil=12000`
→ `tgt = max(18992 − 181851 − 200, 600) = 600`
→ 守卫要求 `new_w ≥ 18992×0.4 = 7597`。

```

同型死锁在另一项目复现：`total=46718, now=15300 → tgt=600 < 6120`。

**次生缺陷 C2（结构性）**：压缩分支**每轮只改 1 个最长小节**。即使压缩成功，`193851 → 18992 之外的最长节仍 11548`，靠"每轮减一节"在 8 轮内也绝无可能从 193851 降到 12000 —— 循环设计与"全局超标 16 倍"的事实不匹配，缺少"整体重写/整稿压缩"的兜底分支（只有 `total < floor` 方向有整稿扩写兜底，`total > ceil` 方向没有对称兜底）。

**次生缺陷 C3（重复调用）**：`word_gate` 在 `stage_polish` 中被调用 **两次**（`[旧版] :3008` "字数门"、`:3369` "装配前再跑一次字数门兜底"）。两次都各跑满 8 轮 → **16 次 writer 调用**。报告里 `writer.calls=24 = 8 章 + 16 轮空转`，即 **2/3 的写手预算（约 17 万 output tokens）被这个死锁循环烧掉，产出零字变化**。

## 2. 节头重复 / 回退缺陷（契约不一致）

### 2.1 三个函数对"节头"的契约对照

| 函数 | 认定规则（旧版） | 产出格式 | 问题 |
|---|---|---|---|
| `_split_full_sections` `[旧版] :2336-2350` | `_SEC_HEAD.match(ln.strip())`（**前缀匹配**） | `{"no": 行首数字, "title": 行内剩余, "text": 行..下一节头}` | 任何"1–2 位数字开头的行"都算节头；**不校验 no 唯一/单调**，重复 02、回退 01 原样保留 |
| `_normalize_section_head` `[旧版] :2655-2663` | 若首行 `_SEC_HEAD.match` 命中 → **整行替换**为 `f"{no:02d} {title}"` | `"NN 标题"` | 对"数字开头的正文行"也会整行覆盖为 `NN 标题`（内容被吞，但比 `_final_clean` 轻） |
| `_final_clean` `[旧版] :1526-1537` | 同上 `_SEC_HEAD.match` | **裸 `"NN"`（标题丢弃）** | ① 整行替换 → 正文被吞（缺陷 D）；② 标题被丢弃，`typeset` 无法取标题（见第 5 节）；③ 不校验单调性 → 438 个节头出现 `01,02,02,01,02,03…` |
| `_normalize_sections` `[旧版] :2449-2453` | 用 `_split_full_sections` 后重建 | `f"{i:02d}\n\n{body}"`（**无标题**） | 与 `assemble`（`"NN 标题"`）相反；同一份稿走不同路径得到不同节头形态 |
| `typeset.split_sections` `studio/typeset.py:73-75` | 要求 `^第N章…$` 或 **`^0?\d{1,2}\s*[、.．]\s*\S{0,24}$`** | `(no,title,body)` | 管线产出 `"01 标题"`（空格分隔）与裸 `"01"` **都不匹配**（必须带 `、`/`.` 分隔符）→ 排版稿永远走"按字数自动切章"退路 |

**旧版根本问题：`_SEC_HEAD = re.compile(r"^#{0,2}\s*(?:第\s*[…数字…]+\s*[章节]|[0-9]{1,2})\s*[:：、.．]?\s*")` 是前缀匹配且无行尾锚**，所以"数字开头 = 节头"，把"24 岁那年…""45个人围着我。"全部误判。

### 2.2 最小复现字符串

```
_SEC_HEAD.match('24 岁那年我被扔进剑冢。') = True   → _final_clean → '24'      # 正文整行丢失
_SEC_HEAD.match('45个人围着我。')            = True   → _final_clean → '45'
_SEC_HEAD.match('58 把残剑同时响。')         = True   → _final_clean → '58'
_SEC_HEAD.match('66 天里我数了三遍。')       = True   → _final_clean → '66'
_SEC_HEAD.match('3 个铜板买了半个饼。')      = True   → _final_clean → '03'
_SEC_HEAD.match('他 24 岁那年')              = False  → 原样保留（说明只锚行首）
```

**重复 02 / 回退 01 的最小输入**（`_split_full_sections` 不做任何唯一性校验）：

```python
demo = "01 第一节\n\n正文A。\n\n02 第二节\n\n正文B。\n\n02 第二节\n\n正文C。\n\n01 第一节\n\n正文D。\n\n03 第三节\n\n正文E。"
=> [(1,'第一节'), (2,'第二节'), (2,'第二节'), (1,'第一节'), (3,'第三节')]     # no 重复 + 回退
_final_clean(demo) => '01\n\n正文A。\n\n02\n\n正文B。\n\n02\n\n正文C。\n\n01\n\n正文D。\n\n03\n\n正文E。'  # 旧版：序列原样保留
```

**真实产物中它的规模**：`final/成稿.txt` 前 40 个节头 = `01,02,02,01,02,03,04,05,06,01,02,01,01,02,03,04,05,06,07,01,02,03,02,01,02,03,04,05,06,07,08,09,10,11,12,13,14,15,18,19`，共 **438** 个，最大 **66**。成因：`ch02..ch08` 里各含 30–109 行"数字开头"的思考计划行，`_final_clean` 把它们逐行改写成裸编号；又因 `assemble` 给每章加了 `NN 标题`，两套编号交织 → 重复与回退。

### 2.3 关于并发修复的复核（关键结论：**没修透**）

当前快照已把 `_SEC_HEAD` 改为整行锚定 + 严格约束（`[快照] :2217-2225`，要求整行 ≤26 字符、无句末标点、无英文、含汉字、编号后不接数字），并加 `_MAX_SECTIONS=60`、`no` 顺延（`:2399-2400`）、`_final_clean` 顺延（`:1538-1540`）。**但用同一份真实产物复测，文字仍在被销毁：**

## 6. 修复优先级与验收（给 Lead 的决策清单）

**P0（必须现在修，否则同类事故会复发）**

1. `llm.py`：writer 角色禁用 reasoning 回退；回退前做"思维链 vs 正文"判别（英文占比 / `_THINK_MARK` 密度），命中即 `LLMError` 重试。
2. `_english_think_leak`：全文判定 + 英文行占比指标；命中即整份重试，禁止落盘。
3. `word_gate` 压缩分支：`tgt` 与守卫同源（`tgt = max(tgt, int(now*0.45))`），并加"单轮无变化即 break"；`total > ceil*1.2` 时直接整稿压缩重写（对称兜底）。
4. `_final_clean`：只对真节头行重编号；"被替换行数/总行数"超阈值打 warn 并写进 report。
5. `cli.py` 淘汰策略：`maxed_words_high` / `final_words > ceiling` 同样淘汰或隔离；`platform_check` 增加上界判定。

**P1（本周内）**

6. `stage_polish` 第二次 `word_gate` 仅在下限方向触发。
7. `report.json` 增加 `assemble_words / final_clean_lost_words / n_sections_raw / word_gate.attempts_detail`，让"落盘≠组装"可见。
8. hybrid 模式补写 `reviews/chNN.json`（哪怕只有 `{"gate":"hybrid","skipped":true}`），并在 `report.review.chapters` 标注"未质检"，避免与"质检通过"混淆。
9. `typeset.split_sections` 兼容 `"NN 标题"`（空格/无分隔符）与裸 `"NN"`。

**验收用例（纯本地、可回归，不调 LLM）**

- 用本项目 `chapters/*.md` 复刻 `assemble` → 断言 `count_words_zh(_final_clean(x)) >= 0.98 * count_words_zh(x)`（当前旧版 0.514、当前快照 0.607，**均不达标**）。
- 断言 `len(_split_full_sections(x)) <= 8`（当前旧版 393、当前快照 42）。
- 断言 `word_gate` 压缩目标满足 `tgt >= now*0.4`（构造 `total=193851, now=18992` 用例，当前必定违反）。
- 断言 `_english_think_leak(ch02.md 内容) == True`（当前为 False）。
- 断言 `typeset.split_sections(成稿.txt)` 返回 8 节且 title 非空。
