# 番茄市场规则提取与书名门落地（2026-10-26）

> 起因：用户要求「搜索高质量内容丰富完善知识库，参考教程提取可用建议」。
> 教程是一期讲番茄新规下如何写书赚钱的视频文字稿。本文只记**可验证、可落地**的部分，
> 不把视频里的主观判断当事实写进项目。

## 1. 教程要点 → 采纳判定

| 教程说法 | 判定 | 依据 / 落地方式 |
|---|---|---|
| 书名必须有看点、有卖点，4 字名签约必死 | **采纳** | 番茄书城信息流形态决定；落地为 `studio/title_gate.py` 卖点分（两种战法取高），`<5` 不放行 |
| 一次性发全部章节申请签约，门槛不只是字数 | 部分采纳 | 官方小课堂确认「短篇 >1 万字可申请签约」；「一次发完」是操作技巧，不进代码 |
| 15 万 / 30 万字是完本签约门槛 | **采纳（修正）** | 36氪/搜狐/游民星空报道一致：2026-10-12 起 Lv.0/Lv.1 新书只能完本签约。写进 `platforms.json` 的 `sign_note` |
| 节奏适配短剧改编，快节奏短句 | **采纳** | 已有章级碎句链门与对白门；本次补「每 600 字一个卡点、段落 ≤3 行、冲突要好拍」进 `prompts/market_guide.md` |
| 扫榜 → 拆书名/简介/前 10 章 → 组合脑洞 | 部分采纳 | 拆书名已落地（`data/market_notes.json` 实证语料）；扫榜本身需要联网抓榜，本项目无外网，**未做** |
| 蒸馏「写作风格 skill」再用它生成正文 | **不采纳** | 本项目已有 `craft.json` + `genre_cards.json` + `style_guide`，再加一层风格 skill 会造成风格来源分散；且它解决的是「模仿某本书」，与本项目「按平台规则生成」的目标不同 |
| AI 全自动写完 30 万字冲完本签约 | **不采纳** | 与本项目「短篇 8000–12000 字」定位冲突；质量换数量的路线已被本项目实测否决（99617 字事故） |

## 2. 网络调研的实际情况（如实记录）

- `web_search` / `multi_search`：能返回番茄官网、应用商店、36氪、搜狐、游民星空、知乎（403 取不到正文）、
  `maliangwriter.com` 签约攻略。**没有任何一条来自 GitHub**，`platform_search(github)` 在本机 fetch failed。
- 能真正取到正文的只有 `fanqienovel.com` 首页（直取 HTML 文本）。从中摘到**真实在更书名**与**章节名**，
  已抄进 `data/market_notes.json` 并标注来源 URL 与抓取日期。
- 结论：本项目做不了「自动扫榜」，只能做「人工抄录的实证语料 + 确定性判据」。

## 3. 四项落地

### 3.1 书名卖点门 `studio/title_gate.py`
- 两种战法：`score_relation()`（身份 + 冲突动作 + 反转钩，15–30 字）、
  `score_concept()`（高概念 + 数量等级 + 关系事件，6–30 字）。`score()` 取高。
- `issues()` 给可执行问题清单；`hint()` 从 `data/market_notes.json` 取**真实榜单书名**当正例。
- `pipeline._title_ok()` 退化为委托；重试时把 `hint()` 拼进提示词；`title_score`/`title_family`
  随 `pitch.json`、`report.json` 落盘。

### 3.2 签约字数门槛 `data/platforms.json`
番茄 `min_words` 8000 → **10000**，新增 `sign_words` 与 `sign_note`（含官方门槛与新规）。
`word_gate()` 的 floor 改为 `max(配置下限, 平台 min_words)`，开跑即打印上调原因。

### 3.3 实证语料 `data/market_notes.json`
12 条真实书名（含战法标注）、5 条章节名模式、3 条签约规则（带来源）、4 条「短篇不适用」的书名。
测试 `test_title_gate_sells_the_hook` 断言正例 ≥8 条且被 `hint()` 引用，防止变成死数据。

### 3.4 提示词侧 `prompts/market_guide.md` 新增「十五、番茄短故事：签约门槛与书名卖点」
写清：门槛（短篇 >1 万字 / 长篇 2 万字 / Lv 等级限制）、书名三段式与真实样本、
短剧改编节奏（每 600 字一个卡点、段落 ≤3 行、冲突要好拍：当面争执 + 可验证物件 + 具体金额）。

## 5. 未做与理由（避免下次重复讨论）

1. **自动扫榜**：需要抓番茄榜单接口/页面并绕过风控，本机无外网且不稳定。当前用人工抄录语料替代。
2. **`hook_density_chars` 落地为确定性卡点检测**：转折词密度这类判据误报率极高
   （本项目在「碎句链」「长句」「欧化·有着落」上各踩过一次），在拿到 20+ 篇标定样本前不上门，
   只留在提示词与 `platforms.json` 里作为写作要求。
3. **简介（summary）卖点门**：番茄简介同样是签约关键，但项目当前简介由 `pitch.md` 生成后直接进
   投稿包，没有独立判据。需要先标定「简介公式」样本，再决定是否加门。
