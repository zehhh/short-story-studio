## 5. `tests/feature_matrix.py` 使用说明

```bash
python tests/feature_matrix.py       # 约 30–60s，离线，零真实 LLM/网络
```

- 输出：逐项 `[ok] / [SKIP] / [FAIL]`，末尾 `N/M 通过（SKIP k，FAIL n）`；无 FAIL 时退出码 0，否则 1。
- `[SKIP]` 语义：**已登记的真实缺陷或测试铁律限制**（如 `kb collect` 会写真实数据目录）。修好缺陷后 SKIP 会自动转为 `[ok]`，无需改测试。
- 隔离：临时配置由 `DEFAULT_CONFIG` 生成（不读真实 `config.yaml` 的 Key），workspace 指向 `workspace/.feature_test/feature_matrix_<pid>/`，每进程唯一，结束自动清理；`run_cli` 强制断言配置在临时目录内。
- 覆盖分组：
  1. **矩阵一致性**：22 顶层 + 33 二级命令与 `build_parser()` 对照；README 命令覆盖率；
  2. **CLI 冒烟**：不依赖真实 LLM/网络的子命令真跑（含 `--help`、mock 全流程、发布、回流、复盘、拆书、看板导出）；
  3. **联动契约**：提示词级验证教训注入、`kb.recall` 逐章注入；调度 argv；KPI/HTTP；断网降级；排版稿节头。
- 与 `smoke_test.py` 的分工：smoke 专注 agent 门禁闭环/断点续跑等**内部逻辑深度**；feature_matrix 专注 **CLI 面 + 模块间契约 + 功能矩阵漂移**，二者互补、不重复。
- 新增检查：写 `def test_xxx()` 加 `@case`，再追加到 `main()` 的 `order` 列表；断言失败会打印 traceback 并计 FAIL。
