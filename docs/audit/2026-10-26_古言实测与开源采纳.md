## 2. 古言题材暴露并修复的 6 个缺陷

### 2.1 碎句链在古言里系统性误报（判据缺「分句数」维度）
「凤冠砸在金砖上，珠翠崩飞，滚了一地。」核心 18 字、同主语、三连句 → 被 `_local_chain` 判碎句。
实测 10909 字成稿：`chain 0.73/千字`，而人工读感是紧凑而非破碎。
**修法**：`_chain_member()` 增加「句中逗号 ≤1」条件（三个以上逗号分句是铺陈/排比，不是碎句），
检测与 `merge_chain_sentences()` 共用同一判据。修复后同一成稿 `chain 0.73 → 0.0`，体检 C → B。
**回扫**：8 篇近期成稿重跑，只有古言那篇等级变化（C→B），都市篇结论不变——说明修的是题材误报，
不是把判据放松到失效。

### 2.2 题材规则全部失效（`report["direction"]` 为 None）
`langqa.scan_for(text, direction)` 依赖 `direction` 决定是否启用 `genre: ["guyan"]` 规则，
而 `audit`/`langqa_full`/`review` 三处都从 `report["direction"]` 取——该字段此前从未落盘。
后果：6 条古言AI味规则（眼底闪过/眸色一沉/嘴角勾起/不怒自威/恍如隔世/现代词混入）从未生效。
**修法**：`stage_polish` 无条件写 `report["direction"]`，三处消费点补 `direction=` 传参。

### 2.3 欧化检测误报（「所谓的」与「有着落」）
`所谓的「恩赏」` 被「的+引号」规则判为翻译腔；`日子有着落` 被「有着」规则判为翻译腔。
**修法**：规则改为 `所谓的(?![「『“‘])`、`有着(?!落|数|了)`，并把同类后接引号的搭配统一放行。

### 2.4 章级对白门缺失（对话占比无人管）
古言 #2 结束在 `对话段占比 0.233`，而市场同类稿件在 0.30–0.40。整条链路只在交付体检里报，
不修。
**修法**：
- `studio/language.py` 新增 `dialog_ratio()`（引号内字数 ÷ 正文字数，唯一口径）与
  `DIALOG_MIN_CHAPTER = 0.30`；
- `studio/agents.py` 章级新增「对白门」：低于 `dlg_min` 连续两轮未提升即 `maxed_dialog`；
- 提示词给出三条可执行改法（把转述改成当场对白、给关键冲突加一句反问、把独白拆成两个人的来回），
  并明确「不许为了凑比例加无信息寒暄」。

### 2.5 方向路由把宫斗选题送到现代方向
`match_direction()` 在零关键词命中时回落硬编码 `"全村人的眼光"`。古言 #3 的 `concept.json`
`direction = 全村人的眼光`，章节小标题同时出现「太后寿宴」和「全村跪求」。
**修法**：`langqa.idea_genre()` 识别选题题材（guyan / modern / 空），`match_direction()` 先按题材
过滤方向池（42 → 5 个古装方向），再关键词打分，仍无命中则取**该题材内最热方向**并打印
`[trope] ⚠ 选题未命中任何方向关键词（题材=('guyan',)），按该题材最热方向 [宫廷权谋] 兜底`。
方向是否古装不只看名字（「换嫁冲喜」「宫廷权谋」不带「古」字），还要看关键词/核心冲突/关键场景。

### 2.6 后宫知识卡与题材完全串味（内容侧最严重）
`data/knowledge/nvzhuhougong.json` 原卡 18 条 facts 全是乡镇一女多男素材（赶集摊位管理费、
信用社存折预约取现、卤味摊掀开锅盖），summary 写「女主聚人核心是先付出再收获」——写手拿这张卡
写宫斗，会把宫斗写成乡镇创业。
**修法**：整卡人工重写（不调 LLM）：summary 定为「制度化的绝境＋可验证的翻盘」；facts 20 条
（份例银/冬炭/卯时请安记档/绿头牌与承幸簿/隔帕诊脉与方子两存/罚序/冷宫非官名/宫女二十五放归/
皇嗣乳母与抓周记档/终号朱笔/凤印六宫/内务府掌事/座次隔屏风/私相授受=交通外臣/降位减宫人/
越次陈请）；scenes 14 / dialogues 12（全部带「」）/ hooks 10 / pitfalls 10 / redlines 4。
**并新增 K09 题材串味 lint**（`studio/kb_lint.py`）：卡片正文里现代词 > 古代词且非跨世界设定
（穿书/快穿/系统）即报 K09；全库 42 卡复跑零问题。

### 3.2 本轮采纳（可验证的代码/数据变更）

1. **32 张题材正文提示卡 → `data/genre_cards.json` + `studio/genre_cards.py`**
   - 每张卡带「开场抓手 / 冲突发动机 / 爽点 / 对话与声线 / 章尾钩子 / 场景颗粒 / 前中后期打法 /
     节奏密度 / 禁止漂移」，以及 1626 本样本的**段落中位字数**与**对话占比**。
   - 注入方式：`_genre_note()` 只取节奏密度 + 禁止漂移 + 样本统计三行（<150 字），全量题材指导
     仍由 `prompts/genre_*.md` 负责（决策 22）。
   - 独立验证价值：宫斗宅斗卡给出「对话约占 29%」，与我们按市场标定的 `DIALOG_MIN_CHAPTER = 0.30`
     互相印证——两条独立路径得出同一量级。
2. **古装方向不注入现代买股文模板（决策 23）**
   `load_genre_guide(cfg, "女主后宫")` 由 6318 字的现代买股文（贵族学院/娱乐圈/选秀综艺）
   改为 2693 字 `genre_guyan.md` + 三条古言后宫硬约束（结局收敛 1v1、情感线必须落在宫规上、
   禁现代买股术语）。

### 3.3 明确不采纳
- **多轮自评-重写循环**（oh-story 的 story-long-write）：本项目已证明 LLM 自评收敛差
  （converge 三轮采纳 3 拒 8、整稿密度反升），改用零 token 确定性返修，不引入更多 LLM 轮次。
- **长篇章纲树**（三层大纲 + 卷）：短篇 8 节用不到，只会增加一次 JSON 截断风险。
- **外部 GitHub 检索自动化**：本机网络受限，不写依赖网络的采集器，避免给流水线加不可用依赖。

## 4. 剩余缺口（诚实记录）

1. **全稿读者团 6.9（`maxed_reader`）**：古言 #4 的读者团终评未达 7.5 阈值。宫斗题材的
   「爽点延迟」与「读者耐心」矛盾比都市题材更尖锐，需要题材级的读者画像权重（当前 6 个画像
   全是都市语境）。
2. **章节门禁仍多轮 `maxed_review`**：主编评分卡口径已自洽（10/10 项全部评估），但古言单章
   常扣在「信息密度低」而非硬伤，说明题材期望与评分卡锚点仍需按题材分层。
3. **古装道具白名单**：`kb.negative_terms` 是全局现代道具表（账册/算盘/欠条），宫斗核心道具
   靠「选题放行」豁免，尚未做到「按题材切换黑名单」。
4. **`prompts/genre_guyan.md` 只有 2693 字**，比买股文那份 6318 字薄，宫廷权谋的「信息战/
   站队/前朝后宫联动」还可继续补。

### 2.7 第 7 个缺陷：「些许」在古装稿是正常书面语，被判 AI 味

古言 #5 初评 **B 可投**，唯一警告来自黑名单「AI味·情态套词」——命中句是
「银霜炭比上月轻了些许」。这条规则原本是 `(些许|隐约感到|几不可闻|毫无征兆)`，
在现代稿里「她心里些许不安」确实是典型 AI 腔，但古装稿里「轻了些许」是正经写法。

**修法（不删规则，改成分题材生效）**：
- `studio/langqa.py` 新增 `_rule_not_genres(rule)` 与 `scan()` 的排除分支：
  `not_genre: ["guyan"]` 表示只在现代题材生效；
- `data/lang_rules.json` 把「些许」从原规则里拆出来，单列一条 `not_genre: ["guyan"]`；
- 验证：同一句话在现代稿命中、古装稿零命中；通用规则（「毫无征兆」）两侧都仍然生效；
- 新测试 `test_lang_rule_not_genre_scoping`（现代必须命中 / 古装必须不命中 / 通用规则两侧都生效）。
- 修复后古言 #5 与 #4 重扫均 **A 可投（零警告）**。

设计取向：**不为了消警告删掉规则**（那会让都市稿继续放过套词），而是给词表加题材维度——
这与「同一判据只能有一份实现」不冲突，因为判据仍是一份，只是带题材条件。
