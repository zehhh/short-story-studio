# 下沉市场写作指导（通用，全题材适用）

## 一、语感基准（先看范例，再动笔）

### 正面范例（知乎盐选真实爆款，学这个语感）

**《锁金宫》开篇：**
> 最近暗卫来得很频繁，李元昭最近在我身上好像有使不完的牛劲，我偷听到他回宫的日子将近，打算用黄金打发我，我心中窃喜。
>
> 我重生而来，前世同村王金花捡到太子并与其成亲，后来李元昭恢复身份，赐金花黄金千两，我很羡慕；这一世我抢先一步救下李元昭，心中狂喜，这富贵终于轮到我了。

**《锁金宫》扔簪名场面：**
> 次日一早，官兵进村，李元昭恢复太子身份，赐我黄金千两；我起身将黄金放到身边，扔了李元昭昨天送的素簪，我告诉他，从今往后，我二人毫无干系。

**《锁金宫》男主失态：**
> 三天后李元昭却带着暗卫返回，他看着满目疮痍的荷花村，身形微动，找簪子未果后，呕出一口心头血。

### 语感要点
1. **短句直陈**：一句一个动作。"我起身将黄金放到身边，扔了李元昭昨天送的素簪"——两个动作一句说完。
2. **第一人称内心独白口语化**："这富贵终于轮到我了""男人可真好骗呐"——像跟闺蜜唠嗑。
3. **数字克制**：全文只出现"千两黄金"一次（核心道具），"三天后"一次（时间锚点）。
4. **细节有功能**：素簪贯穿全文（送→扔→找→呕血→回归）。
5. **时间用事件带**："次日一早""三天后""花灯集会"。

## 二、对话节奏铁律（当前生成稿最大问题）

### 反面范例（禁止这样写）
> 「你说什么？」
> 「你听清了。」
> 「凭什么？」
> 「凭这桩婚事压着你。」
> 「庚帖上的八字是我生辰。」
> 「你生辰被人改了。」
> 「改早还是改晚？」
> 「改到你姐头上。」
> 「我娘没说完。」
> 「她没机会说完。」
——连续几十轮一问一答，像话剧台词，不像小说。

### 正面范例（对话+动作+叙述交替）
> 我指尖掐进掌心，指甲陷进肉里。
> 「你说什么？」
> 邵沉舟把喜秤搁在床头，秤脚磕出闷响。
> 「你听清了。」
> 我盯住断玉，断口里压着残字。
> 「这玉哪来的？」
> 「你娘留的。」
> 门外拍门声急。

### 对话节奏规则
1. **连续对话不超过3轮**：3轮对话后必须穿插动作/环境/叙述，不能连续问答超过6句；
2. **对话带动作**：每2-3句对话之间插一个动作或环境描写；
3. **快节奏场景**（冲突/对峙）：对话70% + 动作30%；
4. **慢节奏场景**（回忆/铺垫）：叙述60% + 对话40%；
5. **每句对话有潜台词**：表面意思 + 真实意图，不写纯信息传递的寒暄。

## 三、数字使用铁律（违反即打回）

### 反面范例
> ✗「对准锁头猛砸三下」
> ✗「本世子护你三天」
> ✗「本世子给你三息」
> ✗「三千两一条的恶犬」
> ✗「三年里走了八十里路，花了三千两银子」

### 正确写法
| 反面 | 正面 |
|---|---|
| 猛砸三下，锁头崩飞 | 铜盆抡圆了砸下去，锁头崩飞，铜钱滚了一地 |
| 护你三天 | 护你到真千金回府那天 |
| 给你三息 | 数到一，你就没命了 |
| 三千两一条的恶犬 | 那犬通身黑毛，项圈挂着铜铃，咬过人牙没拔 |

### 七条铁律
1. **同一数字同节 ≤1 次**；同一数字（含异写：三载/三年/三日/三个/三次）**全篇 ≤2 次**，跨节也不许反复用同一个数；
2. **动作不写次数写结果**："砸下去，锁头崩飞"；
3. **时间锚点用事件不用计量**："护你到真千金回府那天"；
4. **金额要有来路**：千两黄金=太子身价（有诏书背书）；
5. **口头禅式数字全篇 ≤2 次**；
6. **计量单位同段 ≤1 种**：天/年/两/里不连用；
7. **数字梗（999/888/666）只在情绪顶格处用一次**。

### 数字去重专项（当前生成稿高频踩雷，命中即打回）
**"同一个数字反复"病（最高频，覆盖所有数字，不只"三"）**：同一个数字（含异写、阿拉伯数字）全篇 **≤2 次**。注意：把"三"换成"十六/千年"来规避，本质一样，照样打回——
- 数字「三」：三载/三年/三日/三个字/三次/三息/三千两，只留 1 个；
- 数字「十六」：十六年授业/记了十六年/憋了十六年/养了十六年，只留 1 个；
- 数字「千」：封了千年/千年符文/忍了千年/一千年，只留 1 个；
- 数字「二十」：找了二十年/死了二十年/二十多年前，只留 1 个。
- 数字「半」（分数，模型最高频口癖）：半根/半条/半寸/半里/半桌/半裙/半盏/半条命，"半"字全篇 **≤3 次**，同一"半X"（如"半根剑骨"）只留 1 次；
  - ✗ 你身上那半根剑骨 / 这半根剑骨 / 半根剑骨（反复5次）
  - ✓ 你身上那截剑骨 / 这根剑骨（"半根"只在首次点出处用一次，后文用"那截/这根"）
  - ✗ 泼了半桌 / 半条街 / 退了半步
  - ✓ 泼了一桌 / 整条街 / 退了一步
- 改写原则：把"数字+时间"换成**事件、动作、状态**：
  - ✗ 十六年授业、十六年慈爱，都是养药的功夫 / 这话我憋了十六年
  - ✓ 多年授业、多年慈爱，都是养药的功夫 / 这话我揣了许多年
  - ✗ 封了千年 / 忍了千年 / 千年符文
  - ✓ 被封了太久 / 我忍了太久 / 那符文是上古的
  - ✗ 成婚三载 / 第三日 / 三个字
  - ✓ 成婚那会儿 / 隔天 / 就一句
- 判断标准：表达"时间久、仇恨深"，优先用**具体事件、画面、动作**（"这话我到死都记得""他被锁在暗无天日的地底"），数字是最后手段；同一数字出现第 3 次，就必须改写。

**"一下"病**：抖了一下/眨一下/一下一下/瞧了一眼……全文 "X 了一下/一眼" ≤3 次，且不许连续两段出现：
- ✗ 裴烬的肩抖了一下 / 眼睛都没眨一下 / 拍得急，一下一下的
- ✓ 换动作换结果：肩抖了一下 → "他的肩塌下去"；眨一下 → "眼都没眨"；一下一下的 → "拍得整扇门跟着晃"

**"一+量词"静态罗列病**：不用"一块/几粒/一根/几串"去静态数物件（吃的、摆的、吹的），直接写状态和动作：
- ✗ 我拿起一块枣泥酥，掰开。馅料里嵌着几粒瓜子仁
- ✗ 风把丝线吹起来，一根一根，亮的
- ✓ 我掰开枣泥酥，馅料里滚出瓜子仁，脆生生硌牙；丝线让风吹起来，亮闪闪铺了一院子

**"计量型描写"病（动作编序号/时长/件数，命中即打回）**：禁止用"第几页/几息/几年/一份/几味"给动作配**计数、计时、编号**，动作直接写结果：
- ✗ 翻到第三页，停住了 → ✓ 翻到那页，他手指停在行间
- ✗ 手悬在半空停了两息 → ✓ 她手悬着，没接茶
- ✗ 毒酒的味道我记了五年 → ✓ 那味道我到死都记得（或写具体画面）
- ✗ 改了三味药 → ✓ 连方子都被她动过手脚
- ✗ 抄了一份，抄在细绢上，折成方胜，塞进点心盒子里 → ✓ 把功绩抄在细绢上，折成方胜塞进点心盒子
- 判断标准：把"第三页/两息/五年/一份/三味"换成"那页/半晌/一辈子/一张/几味"，句子还成立吗？成立就说明数字是装饰，删掉。

**"碎句拆写"病（一个动作拆成三四个超短句逐帧报，命中即打回）**：动作链要"边做边推进"合并成一句或两句，禁止"动作A。动作B。动作C。"逐帧拆解：
- ✗ 翠屏把方子取来，沈院判对着光一页页翻，翻到第三页，停住了。
- ✗ 我让翠屏把张武的功绩抄了一份，抄在细绢上，折成方胜，塞进点心盒子里。
- ✓ 翠屏取来方子，沈院判对着光翻了几页，手指停在某行上。
- ✓ 我把张武的功绩抄在细绢上，折成方胜塞进点心盒子，让翠屏送出去。
- 判断标准：删掉任一个逗号后的短句，动作链还完整吗？完整就是拆碎了，合并它。
- 例外：动作本身有停顿/转折节奏时允许短句（"他站着没动。半晌，坐下了"），但**纯推进型动作链**（取→翻→停、抄→折→塞）必须合并。

**"节拍碎句"病（用标点给动作打节拍凑节奏，命中即打回）**：事件要一次推进到位，禁止"一下，隔一会儿，又一下""一步，两步，三步"式逐拍报数：
- ✗ 一下，隔一会儿，又一下。节奏很慢，像有人边走边数步子。
- ✗ 她迈一步。咚。又迈一步。咚。（逐帧报动作）
- ✓ 搪瓷缸磕地的响，隔一会儿一声，越来越近。
- ✓ 她一步步走过来，每一步都像踩在我心跳上。

**"信息罗列式白描"病（时间/地点/外貌/动作一句一个报幕，命中即打回）**：信息要压缩合并，能一句带过的绝不拆成三句：
- ✗ 十分钟前我从东侧电梯上来的。十三楼，值班室。电梯门开的时候，走廊尽头站着个穿蓝条病号服的老太太。头发花白，背对着我，手里攥着个搪瓷缸。（四句报幕）
- ✓ 十分钟前，我从东侧电梯上来，走廊尽头站着个穿蓝条病号服的老太太，花白头发，背对着我，手里攥着个搪瓷缸。（一句装完时空+人物+关键外貌）

**"X，没Y"模板病（AI腔定性句，命中即打回）**：禁止"名词+逗号+没+名词"偷懒定性（女声，没温度/灯光，没亮透/空气，没动静）——改成具体可感画面或比喻：
- ✗ 女声，没温度，从天花板的喇叭里挤出来。
- ✓ 女声从天花板的喇叭里挤出来，像含着一口老痰，每个字都黏糊糊的。

**"宾语+数量后置"语序病（数量词当逗号补语，命中即打回）**：动词的宾语 + 数量/修饰，必须按正常语序**前置**（"点了三根香"），禁止拆成"动宾，数量补语"（"点香，三根"）或"名，数量/状态"（"红绳，三枚"）：
- ✗ 进门先点香，三根，炉前一根，走廊一根，值班室一根 → ✓ 进门先点了三根香——炉前一炷、走廊一炷、值班室一炷
- ✗ 我先点了香，三根 → ✓ 我点了三根香
- ✗ 手腕上缠着红绳，三枚铜钱 → ✓ 手腕上缠着系了三枚铜钱的红绳
- ✗ 白布，盖得严实 → ✓ 白布盖得严实
- ✗ 纸上是铅笔字，一行小字 → ✓ 纸上有行铅笔写的小字
- 判断标准：把逗号后的数量/状态挪回名词前面（"三根香""严实的白布"），句子通顺吗？通顺就是语序倒了，合并重写。**数量词一律紧跟所修饰名词，不许单独拎到句尾当补充说明。**

**"X了一下，X了一下"碎拍病（动作碎拍报数，命中即打回）**：同一动作链禁止用"……了一下，……了一下"逐拍报——动作要一气呵成写结果：
- ✗ 他推门，推了一下。门板晃了一下。他又推了一下。
- ✓ 他推门，门板吱呀一响，纹丝没动，又推了一下才开。


**"机制性计数变执念"病（规则数字写成人物执念，命中即打回）**：规则怪谈/游戏规则类题材里"数步子/数几下/几点几分"是**机制设定**——只许在规则宣告处出现一次，之后用场景动作自然呈现，**禁止人物反复"数到第几步/别数/数了几声"式念叨**，全篇同类"数X"表述≤2次：
- ✗ 「别数她走了几步。会死。」（开篇就念叨，像人物有数数执念）
- ✗ 我数了。反应过来的时候我已经数到第七步。（反复数步过程）
- ✓ 规则宣告写一次（守则条文/广播原话），后续只写她走了一步、又一步，读者自己会数——**把"数"的悬念留给读者，不替读者数**

## 四、细节描写详略规则

### 三问法则
写一个细节之前，先问：
1. 删掉它，故事损失什么？（答不上来就删）
2. 这是人物会注意的，还是作者在炫技？（后者删）
3. 这个细节后面还会用到吗？（不会用就删）

### 详略分配
- **详写**：冲突瞬间（一句话、一个动作写满）；关键道具（首次出现写清楚，后面不重复描写）；
- **略写**：背景设定（"她爹是炼丹的"就够了）；环境（一句带过）；外貌（只写一处特征）。

### 反面范例
> ✗ 宋敬堂翻开族谱，纸角磨得发亮。（族谱后面没再用）
> ✗ 陈伯站在天井中央，腰间一串钥匙叮当作响。（钥匙后面没再用）

### 列举式白描禁令（当前生成稿高频踩雷，命中即打回）
**禁止**用"名词/形容词 + 逗号碎片"罗列画面，像在报清单：
- ✗ 风把丝线吹起来，一根一根，亮的。
- ✗ 我揭开食盒盖子——枣泥酥，油亮亮的，摆得齐整。
- ✗ 屋外天色暗透，屋里没点灯，我坐在黑地里，手里黏着甜腻。
- ✗ 她站着，头发散着，脸上挂着泪，衣角湿了一片。

**正确写法**：把画面长进动作/剧情里，一个画面只取**一个最有用的细节**，且这个细节要么推动情节、要么泄露人物状态：
- ✓ 风把丝线吹起来，亮闪闪铺了一院子，徒弟们追着收。
- ✓ 揭开食盒盖子，枣泥酥码得整整齐齐——她病得起不来床，倒有精神头做点心？
- ✓ 屋里没点灯，我坐在黑地里，手里的碎渣黏着枣泥的甜腻。

**一条画面铁律**：描写一个场景，最多 2 个感官细节（视觉/声音/气味/触感选两个），选能体现人物处境的那两个；其余全砍。

### 正面范例
> ✓ "扔了李元昭昨天送的素簪"——素簪后面会找、会呕血、会回归。
> ✓ "我把袖中那张撮皱的庚帖副本拍在桌上。帖角刮痕清晰"——刮痕后面会翻案用。

## 五、25种"平淡型"问题诊断（动笔前自查）

| 症状 | 原因 | 改法 |
|---|---|---|
| 情绪平铺，全文语调一致 | 害怕表达极端情绪 | 设计情绪过山车：悲→喜→惊→怒 |
| 节奏拖沓，描写过多 | 迷恋细节 | 删减30%，用三幕式压缩 |
| 对话水化，像日常寒暄 | 只传递信息无潜台词 | 每句对话设计"表面意思+真实意图" |
| 反派乏力像工具人 | 动机单薄能力平庸 | 给反派正当动机+压倒性优势 |
| 巧合推进无因果 | 懒于设计因果链 | 用"因此/但是"替代"然后" |
| 大段背景介绍 | 急于展示世界观 | 信息切碎，通过行动和对话释放 |
| 所有角色说话一样 | 缺独立声音设计 | 每人设计独特口头禅与禁忌词 |
| 输赢无所谓 | 没有真正可失去的 | 提高赌注：生死/尊严/挚爱 |
| 反转突兀 | 伏笔不足 | 前期埋3处不易察觉的线索 |
| 长期同一空间 | 场景变换不足 | 每3000字换一次主要场景 |
| 闪回过多 | 时间工具不当 | "现在危机+过去揭秘"双轨制 |
| 只有视觉无嗅听触感 | 忽视多感官 | 每段环境描写激活两种感官 |
| 主角总被推着走 | 缺主观能动性 | 让主角主动做"错误但勇敢"的选择 |
| 词汇重复句式单调 | 缺修辞意识 | 禁用"很/非常/突然"等泛化副词 |
| 章末无钩子 | 不懂悬念维持 | 每章结尾制造"信息缺口"或"新危机" |
| 同类情节反复 | 缺情节多样性 | 情节类型轮换 |
| 情绪告知型 | 直接写"他很伤心" | 用动作/神态/环境折射情绪 |
| 结构松散像散文 | 缺统一框架 | 套三幕结构骨架 |

## 六、戏剧冲突技巧（26种）

- **冰山法则**：只展示10%的危机，设计90%隐藏信息通过细节泄露；
- **钟摆冲突**：关系在极端间摆动——亲密→决裂→亲密；
- **锁链困境**：解决一个问题引发更大问题——A方案→意外后果→B方案→更糟；
- **道德绞杀**：两种正确互相矛盾，让主角在"对vs对"中抉择；
- **信息炸弹**：前期埋信息碎片，高潮时拼合引爆；
- **时间绞索**：设置可见倒计时，中途加速；
- **信任崩塌**：插入误解证据，让合理怀疑升级；
- **代价递增**：每次靠近/和解都付出比之前更大代价；
- **身份错位**：错误时间以错误身份相遇，揭露时爆发；
- **记忆碎片**：用回忆/插叙逐步揭示真相，每层关系撕裂一次；
- **先甜后虐**：先给足糖建立情感依赖，再精准下刀；
- **旁观者视角**：通过配角视角让读者看到主角的惨——当事人隐忍不说；
- **克制描写法**：越是剧痛越要轻描淡写，留白比直给更有杀伤力；
- **错位付出**："我给你的正是你不需要的"；
- **时间差虐法**："当我终于学会爱你，你已经不在原地了"。

## 七、节奏把控（晋江实战节拍）

### 开篇节奏
- 黄金三章定律：主角亮相、核心冲突、世界观锚定；
- 切入点选最有张力的瞬间；
- 前3行定生死：手机屏幕3行内必须出现冲突或悬念。

### 情节结构
- 三幕式：起25%、承50%、转合25%；
- 每3-5章小高潮，全文3-5个大高潮（30%、60%、90%处）；
- 卡点艺术：章末停在悬念或情绪高点。

### 情绪节奏
- 爽点：每3-5章小爽点，先抑后扬；
- 虐点：小虐每10章一次，大虐全书2-3次，虐后必有糖；
- 笑点：每章至少1个轻松点。

### 对话与叙述配比
- 快节奏（冲突/对峙）：对话70% + 动作30%；
- 慢节奏（回忆/铺垫）：叙述60% + 对话40%。

## 八、导语写法（300-400字，六句框架）

### 结构
1. **第一句**：噱头/反常识事件；
2. **第二句**：接住情绪，放大冲突；
3. **第三句**：叠矛盾/反转；
4. **第四句**：再叠一层；
5. **第五句**：主角立场/反常反应；
6. **第六句**：钩子（让读者必须翻页）。

### 导语示例
> 被拐的第五年，我生下了强奸犯的孩子。
> 等顾辞带着警察找到我时，我还没出月子就又怀上了二胎。
> 他怕我寻死，寸步不离地守了我整整三年，就连上厕所他也要跟着。
> 直到同期的病友交流会上，他认识了单亲妈妈许绍。
> 两人围绕着我，很有共同话题。
> 他们第一次通电话，是在我发病后的深夜。
> 「顾先生，照顾病人很累的，尤其温小姐发病时还会全身颤抖，大小便失禁。」
> 第二次……第三次……
> 可……

### 禁忌
- 不穿插回忆；环境/外貌/心理描写 ≤1 句；不辞藻堆砌；事件 ≤3 件。

### 短篇导语 ≠ 长篇开篇（当前生成稿高频踩雷，命中即打回）
短篇导语是"预告片"：把**最炸的冲突瞬间**拎到最前面（死亡/背叛/反转/威胁当面发生），再往回补一句设定；长篇开篇才允许"先铺环境→交代身份→引出冲突"的慢热顺序。短篇没有这个耐心。

判别标准：导语前 100 字里必须出现**反常事件 + 主角反应/立场**——读者要立刻知道"出事了、谁、怎么站队"。

- ✗ 长篇式（状态铺陈起手）：「再睁眼，我坐在坤宁宫的东暖阁里，面前跪着一溜儿宫人。翠屏端着茶盏上来……」——读者划走
- ✓ 短篇式（冲突瞬间起手）：「毒酒递到我嘴边那刻，我忽然想起上辈子是怎么死的。皇帝站在帘后，贵妃捏着我的下巴：姐姐，喝了吧，宫里不养废后。我笑了——这杯酒，我记了两辈子。今儿，该您先尝。」
- ✗ 长篇式（背景交代起手）：「我当皇后的第五年，皇帝亲手端来一盏酒……」
- ✓ 短篇式：「那盏酒端到面前时，殿里的人都等着看我喝。我端起它，转身递给了身后的太监：去，让贵妃先尝。」

## 九、夸张手法（情绪顶格时用）

- **排比叠加+转折**：表现忍让——"林晚晚舔了傅司礼十年，接受他心口文了白月光名字，接受他在床上叫白月光昵称……"；
- **数字梗**：只在情绪顶格处用一次——"结婚一个月，傅司礼睡了999个女人"；
- **玩命夸张**："门外架了99台大炮，你不和我走，我们同归于尽"——只在最终对峙用一次。

**逻辑底线**：无身份者不得突然翻云覆雨、小人物不得随意调动公权力。
**夸张边界**：夸张只限情绪、场面、排场（99台大炮、七天七夜、999个女人），**绝不能违背身体极限和物理常识**——大出血不救会死、重伤昏迷不会自己醒、高烧不是灌碗凉水能压住的。夸张的是"多"和"狠"，不是"人的身体能做到什么"。

## 十、现实逻辑与身体常识铁律（非超自然题材必守，命中即打回）

**原则**：除非题材明确有超自然设定（修仙/玄幻/规则怪谈等，且只在设定范围内超自然），否则人物的身体、生理、物理反应必须符合基本常识。

### 常见翻车（命中即打回）
| 翻车写法 | 问题 | 正确改法 |
|---|---|---|
| 滑胎/大出血后"熬了两天，自己爬起来熬红糖水" | 大出血不救治会休克死亡 | 当天就有人施救或女主强撑着出门求医，昏迷被救，躺养多日 |
| 高烧"灌了两碗凉水，天快亮清醒过来" | 高烧不是喝水能退的 | 烧到昏迷，翠屏求医抓药，或自己咬牙去医馆，躺了几天 |
| 断腿/重伤第二天"下地走动" | 伤后恢复要有时长 | 躺养半月，拄拐/有人扶，慢慢恢复 |
| 中毒后"睡一觉就好了" | 毒需要解药/催吐/就医 | 找解药、催吐、请大夫，留后遗症 |
| 溺水/吊打后"缓过气来就能说话打人" | 恢复过快 | 呛咳半天、声音嘶哑、被人架着 |

### 三条底线
1. **伤病的处置要配得上严重程度**：小伤小治、大伤大治；请医、抓药、躺养要写出来；
2. **恢复时长要合理**：按伤势轻重给天数/周数，期间动作受限（不能跑的就不跑、不能提重的就不提）；
3. **情绪和场面可以夸张，身体不能夸张**：人物可以命大（差一点死），不能违背生理极限（流着能死人的血还自己忙活）。

## 十一、账本/记账道具硬约束（非生意主线禁入，命中即打回）

**非生意主线（主角不经营铺子/账房/查账），全文禁止出现**：账本、账册、记账、算盘、对账、欠条、记仇小本本，以及"这账我记下了""心里的小本本"类说法。

- 记仇/算计用别的载体：眼神、狠话、当面点破、攥碎的信物、留的证据（信件/字据/嫁妆单）——**证据类道具可以，记账式人设不行**；
- 例外：主角的主线就是做生意/管账（开铺子、经商、账房先生），"账"只出现在经营行为本身（盘账、进货、结算），**不许变成记仇工具**（如"我把它记在账上"）；
- 反例：假账本装样子、拿算盘核账、翻旧册子记仇——全删。

## 十一点五、时代设定一致性硬规则（古代/现代混搭，命中即打回）

**先判定故事的时代背景（古代/现代/架空/修仙），全文（导语+正文）的人物身份、职业、称谓、器物、制度必须属于该时代，禁止跨时代混搭：**

- **古代/古言/宫廷/修仙背景**：禁止现代职业（医生/警察/律师/护士/心理医生/程序员/工程师/会计等）、禁止现代器物与科技（手机/电梯/监控/手术刀/CT/电脑/电灯等）、禁止现代称谓与表达（"老公""下班""打车""开会""项目"等）：
  - ✗ 古代背景出现"心外科医生"（心外科的江砚，是她从小绑到大的青梅）→ 改古代可替代身份：太医/名医世家子/药铺少东家/军营军医
  - ✗ 古代背景"手机震了震""打开电脑查记录" → 改：家仆传话/飞鸽传书/递帖子/信笺/当面问
  - ✗ 修仙背景"他在医院值夜班" → 改：他在丹房守炉/在药庐坐诊
- **现代背景**：禁止古代称谓（王爷/本宫/格格/奴才/圣旨/上朝等）、禁止古代器物制度（凤冠霞帔当日常装、后宫/妃嫔/太监）——除非明确是"古穿今/穿越"且遵循穿越设定；
- **架空/玄幻**：允许本世界观专属体系（宗门/炼丹/心法/魔法/科技），但**体系内部称谓要一致**——古代风宗门用"师兄/师姐/长老/掌门"，不用"医生/护士/经理"；星际/现代风则反之；
- **判别标准**：把任何一个职业/器物/称谓单独拎出来问"这东西在这个时代存在吗？"——不存在就改写；同一篇里出现"心外科医生"和"跪在宫门外"并存，直接打回。

## 十一点六、倒装句与AA叠词表述病（命中即打回）

### 倒装对比句
**禁止**"眼前现状 + 破折号/逗号 + 过去对比"的倒装语序——时间状语被垫到句尾，读起来绕。正常语序=时间在前、现状在后，或一句内直接对比：
- ✗ 匾上落满灰，边角缺了一块——我走那年，这匾还是新的。
- ✓ 这匾我走那年还是新的，如今落满灰，边角缺了一块。
- ✗ 她鬓边一点碎钻晃眼——当年嫁进来那日，她穿的就是这身。
- ✓ 当年嫁进来那日她穿的就是这身，如今鬓边碎钻晃眼，人却不是当年那个了。
- 判断标准：破折号/逗号后的内容是不是"过去的时间+过去的对比"？是就提前，改成时间在前。
- 例外：对话里人物故意倒装说话（台词节奏）允许，叙述不允许。

### AA叠词罗列
**禁止**"一笔一笔/一级一级/一层一层/一个一个/一寸一寸/一步一步/一下一下"这类**重复量词/副词修饰**堆在动作上——叠词滥用是AI腔重灾区，节奏拖沓：
- ✗ 这山上的丹方，有一半是我娘一笔一笔写下来的。
- ✗ 我提着药箱，一级一级往上走，没人拦。
- ✗ 雪一层一层压下来，把山道埋了。
- ✓ 这山上的丹方，有一半是我娘亲手写下来的。
- ✓ 我提着药箱往上走，没人拦。
- ✓ 雪越压越厚，把山道埋了。
- 判断标准：叠词删掉句子还完整吗？完整就删（"一笔一笔"→"亲手"、"一级一级"→直接"往上走"、"一层一层"→"越压越厚"）；全篇保留≤2处有特殊节奏需要的叠词（如拟声、强调动作递进），其余全改。

## 十二、神态与表情写法（替代"肌肉绷了一下"类句式）

**禁用高频**："XX的肌肉绷了一下/眼神闪了闪/嘴角抽了抽/肩抖了一下/喉结动了动/眸色一暗"这类**身体部位+小动词**机械组合，全篇≤3次且不许连续两段；**"X了一下/瞧了一眼/笑了一下"类"动词+一下/一眼"小动作组合全篇≤5次**（生理性"绞一下/抽一下"疼痛描写除外）。

**正确做法**：用**看得见的行为结果**写情绪，动作幅度配得上情绪强度。

### 原文语感参考（素材拆解《锁金宫》）
> "李元昭看着消失在溪水中的簪子，眼底猩红，仪态尽失。"
> "身形微动，找簪子未果后，呕出一口心头血。"
> "他恢复太子身份，我起身将黄金放到身边，扔了李元昭昨天送的素簪。"

——大情绪配大动作（呕血、眼底猩红、仪态尽失）；小情绪也配具体动作结果。

### 替换表
| 情绪 | 反面（禁用） | 正面（行为结果） |
|---|---|---|
| 紧张 | 他脸上的肌肉绷了一下 | 他喉结滚了滚，端起茶盏灌了一口，手背青筋绷着 |
| 吃惊 | 她的眼神闪了闪 | 筷子掉在桌上，她半天没想起捡 |
| 心虚 | 他的表情僵了一下 | 他不再看人，眼睛钉在茶盏上，指头绕着杯沿转 |
| 强忍 | 他的嘴角抽了抽 | 把到嘴边的话咽回去，端碗喝了一大口 |
| 动怒 | 他眸色一暗 | 手里茶盏磕在桌上，水泼了半桌 |
| 心死 | 她心里一阵悲凉 | 她把簪子拔下来，扔进灶膛，看火舌把它舔干净 |

**铁律**：情绪写结果，不写"部位反应"。读者要看到人物**做了什么**，不是"哪里动了一下"。

## 十三、信息密度与节奏铁律（当前生成稿最大短板：冗余太多、密度低、节奏慢）

### 底层逻辑（编辑/读者真实行为）
盐言/知乎短篇是"高密度、快节奏、强沉浸"阅读：编辑审稿=3秒扫导语→10秒掠前300字→60秒通读前1000字；读者在信息流里划走只需一瞬。**前1000字定生死**——这千字内立住人物、引爆冲突、埋下悬念，其余万字才有人看。短篇靠"删"不靠"写"：删掉10%-20%的字数，节奏立刻起飞。

### 一条总纲
**每一句话都必须服务主线（推进剧情/塑造人物/引爆情绪/制造悬念），否则删掉。** 动笔时对每个句子问：删了它故事会缺什么？答不上来就删。

### 密度≠短小（防止把稿子删短，命中即打回）
**删字针对的是废话，不是情节**。以下做法是把"删"用歪了，全部禁止：
- ✗ 为了精简把关键冲突/对话/反转砍掉，稿子只剩骨架——**该写的事件一个都不能少**；
- ✗ 总字数目标 9000 却只写 5000，还自称"信息密度高"——**密度高≠字数少**：密度是"每句话都有用"，不是"少写字"；
- ✗ 单节只写 300 字就收——单节必须 650-900 字，一个完整事件+一个钩子；
- ✓ 正确顺序：先写满字数（每节650-900字，事件写全、对话写足、冲突写透），再逐句删废话（虚词/解释/重复/过程动作），删完重新数一遍，不足就补具体内容——**最终必须同时满足"每句有用"和"字数达标"**。

### 信息密度五则
1. **一句话装两个信息**：动作+目的、对话+潜台词、细节+后果合并成一句，禁止一句只报一个无意义动作（"她端起茶杯。她喝了一口。"→"她灌了口茶，压住翻涌的恶心"）；
2. **省略读者能脑补的**：过程性动作不写（开门、落座、行礼、斟茶这类过渡动作读者会自动脑补），直接写"结果/异常"——"我推门进去"不写，直接写门后发生了什么；
3. **一段一个功能**：每段只干一件事（推进冲突/交代关键信息/揭示人物），一段内混两件事就拆；段落功能可叠加（冲突段里顺便抖一个信息）；
4. **场景简化**：不铺环境、不交代来龙去脉，场景只为冲突服务——人物进场景就开撕，空间描写≤1句且带情绪；
5. **对话戏剧化**：用简短对话完成大量信息传递，一句台词同时给"信息+态度+关系"（"这杯酒，该你喝了"=下毒+立场+身份），禁止寒暄式废话。

### 零缓冲强切入（开篇）
- 第一句话就是**事件最锋利的切口**，拒绝一切铺垫：不写主角年龄/职业/外貌、不交代家庭/城市/天气、不渲染心情、不分析动机、不回忆过往；
- ✗ 我是刑侦队长，从业十二年，见过无数尸体……（铺垫）
- ✓ 法医掀开白布，死者手腕内侧，赫然纹着我女儿幼儿园的校徽。（第一句即事件）
- ✗ 婚后第三年，我渐渐感到疲惫……（铺垫）
- ✓ 产房门外，婆婆把缴费单揉成团塞进我手里：「生个女儿，医药费自己扛。」（第一句即冲突）
