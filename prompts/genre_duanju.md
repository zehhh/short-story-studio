# 短剧改编向·专项指导（direction 含「短剧/改编/duanju」或目标为红果改编时注入）

> 本指导是**风格层**，可与任何题材（修仙/古言/现代/悬疑）叠加。
> 核心目标：让小说天然适配红果短剧分镜，**拿到改编机会**。
> 节奏铁律：短句、快节奏，比当年的飞卢还快，全面适配短剧。

## 一、短剧的底层逻辑（先想清楚再动笔）

1. **强画面、弱心理**：短剧是"看"的，不是"读"的。
   - 一切情绪、信息、冲突都要能**演出来、拍出来**：用动作、表情、对话、场面，不用大段内心独白；
   - 删掉"她想了很久""他心里五味杂陈"这类拍不出来的句子，改成一个动作或一句台词。
2. **冲突前置、零铺垫**：
   - 第一节（=短剧第一集）必须有强钩子：**核心冲突、人设锚点、情绪钩子**三件事在开头几百字内完成；
   - 反面：开篇大段介绍世界观、背景、主角从小的经历；
   - 正面：开局即一场具体的冲突场面（被赶出门、被当众羞辱、被退婚、被陷害），画面直接砸到读者脸上。
3. **节奏比飞卢还快**：
   - 短句短段，一段最多 1-3 行；能一句话说清的绝不拆成碎句；
   - 每一节都要推进剧情或升级冲突，**不允许原地踏步的过渡段**；
   - 信息密度大：每一节都给读者新的刺激（新冲突/新反转/新信息/新爽点）。

## 二、卡点结构（短剧改编的命门，严格执行）

1. **每 3 节一个小高潮**：情绪叠加后**立即释放**，然后马上引入下一个矛盾点，不让读者情绪落空；
2. **关键卡点**：在第 3 节、第 10 节（或全文约 1/4、1/3 处）设置"**期待感爆炸**"的卡点——
   - 通常是：身份初露、第一次打脸、最大秘密的一角、绝境中的转机；
   - 卡点要**断在最吊胃口的位置**（冲突爆发前一秒 / 真相将揭未揭 / 新危机出现）；
3. **每节开头给"噱头"、结尾留"钩子"**：
   - 开头：一句反常的话/一个冲突动作，把人拉住；
   - 结尾：一个悬念、一个反转、一句狠话，逼读者点下一节。
4. 情绪曲线：**每 3 节一个小高潮，每 10 节一次身份/实力升级**，层层叠加，不回落。

## 三、人物关系公式（红果验证过的爆款配置）

- **美强惨女主**：有本事、有惨史、有反差，情绪和行为有明确动机；
- **偏执男主**：强大、占有欲强、对女主执念深（可追妻、可敌对、可真香）；
- **恶毒女配/反派**：负责制造羞辱和压迫，坏得直接，推动女主反击；
- **神秘帮手**：关键时刻出现，给女主资源/信息/靠山，身份可留悬念。

## 四、情节公式（开局受辱→绝境反转→身份揭秘）

按此六拍推进，每一拍都要有具体场面：
1. **开局受辱**：主角被踩在最底层（被退婚/被陷害/被赶出/被夺走一切）；
2. **意外获能力/转机**：重生记忆、隐藏身份、金手指、神秘帮手、真本事曝光；
3. **首次反击**：小范围打脸，让欺压者吃瘪，立住人设；
4. **遭遇压制**：反派加码，主角陷入更大危机（制造低谷）；
5. **绝境反转**：主角亮出真正底牌/身份，一击翻盘（最大爽点，放在卡点）；
6. **身份揭秘 + 清算**：所有伏笔回收，仇人伏法，主角站上高位，情绪彻底释放。

## 五、改编向语言红线（与项目其他红线叠加）

- 禁大段心理描写、环境文艺描写、无效铺陈；
- 禁注水、重复堆砌、机械扩写（番茄质量红线）；
- 对话要能直接当台词：口语、有冲突、有潜台词，不说废话；
- 每场戏都要能标"景、时、人、动作"——写不出来就说明这场戏不该存在。

## 六、自检（交稿前逐条过）

1. 第一节是否在几百字内完成"冲突+人设+钩子"？
2. 每 3 节是否有一个小高潮且情绪立即释放？
3. 第 3/10 节是否有"期待感爆炸"的卡点并断在最吊胃口处？
4. 每节开头有没有噱头、结尾有没有钩子？
5. 有多少句子是"拍不出来"的心理/背景？删掉改成动作或台词。
6. 有没有不推进剧情的过渡段？删掉。
